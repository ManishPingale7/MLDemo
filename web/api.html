LOCAL API REFERENCE

One transaction in. One decision out.

The API loads a quality-gated local model release. It applies the same cleaning, features and fitted pipeline as the notebooks. No network services are used for prediction.

POST /predict

Send JSON with the eleven transaction fields below. Do not include is_fraud: the actual label is never a prediction input. Scores are model outputs, not calibrated fraud probabilities.

{
  "txn_id": "DEMO-001",
  "timestamp": "2025-03-10T02:00:00",
  "customer_id": 100,
  "amount_inr": 7200,
  "customer_avg_amount_inr": 600,
  "merchant_category": "electronics",
  "city": "Delhi",
  "distance_from_home_km": 950,
  "device_type": "desktop",
  "is_new_merchant": 1,
  "txns_last_1h": 3
}

Response fields: txn_id, score, threshold, decision (approve/review), model, release, data_version and latency_ms. The actual score depends on the active fitted model; the dashboard shows the real response.

Try it from Python

import requests

transaction = {
    "txn_id": "DEMO-001", "timestamp": "2025-03-10T02:00:00",
    "customer_id": 100, "amount_inr": 7200,
    "customer_avg_amount_inr": 600, "merchant_category": "electronics",
    "city": "Delhi", "distance_from_home_km": 950,
    "device_type": "desktop", "is_new_merchant": 1, "txns_last_1h": 3,
}
response = requests.post("http://127.0.0.1:8765/predict", json=transaction, timeout=10)
response.raise_for_status()
print(response.json())

Other endpoints

EndpointPurpose
GET /healthCheck readiness and the active release.
GET /api/modelSee release metadata, validation metrics and replay provenance.
GET /api/samples?mode=balanced&offset=0&count=1Get labelled validation examples for replay. Modes: natural, balanced, routine, fraud. Labels stay outside prediction requests.
POST /api/reloadLoad the latest locally released artifact without restarting. In-flight requests finish on their original snapshot.
GET /openapi.jsonRead the machine-readable schema.

Input rules

Amounts and usual spend must be positive and finite. Distance may be null; device may be null or unknown. Timestamps must be local times without timezone suffixes, matching training. Invalid inputs return HTTP 422. Unknown extra fields, including the label, are rejected. This localhost teaching service has no login or production hardening.

Release a model

python scripts/deploy_model.py
python scripts/deploy_model.py --candidate models/baseline.joblib
python scripts/deploy_model.py --rollback

The first command evaluates the candidate before activating a new local release. The baseline command demonstrates a blocked release and exits with code 1. Rollback requires a previous release. After changing releases, click Reload model in the dashboard.
